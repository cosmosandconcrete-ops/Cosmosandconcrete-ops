## How I run agents

These principles show up in every system above:

- **Authorization before action.** Written permission and locked scope
  before any agent touches a client's systems.
- **Approval gates.** Consequential or irreversible actions wait for a
  human's explicit approval — per action, not blanket permission.
- **Audit everything.** Every action an agent takes is logged,
  timestamped, and attributable, so any outcome can be reconstructed.
- **Kill switches and rate discipline.** Any running process can be
  halted in one step, and automation is rate-limited so "thorough" never
  becomes "accidental denial of service."
- **Verify delivery, not just success.** A job reporting "done" is not
  proof the message arrived or the booking landed; systems check the end
  state the way the owner actually sees it.
- **Scripts where scripts suffice.** Mechanical checks run as scripts at
  near-zero cost; AI agents are reserved for work that needs judgment.
  Token spend is tracked like any other operating cost.
- **Honest capabilities.** Agents never invent prices, guarantees, or
  facts. When a system can't do something, it says so and routes to a
  human.
